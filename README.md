# WellSync

### AI-Powered Health & Wellness Platform

WellSync is an AI-powered health and wellness web platform designed to provide users with a range of tools for monitoring and improving their overall well-being.

The platform combines menstrual cycle tracking, emotion detection, neuroacoustic sound therapy, gesture-based controls, and interactive stress-relief games in one application. It also includes a built-in chatbot to guide users through the different features.

## Key Features

- **Menstrual Cycle Tracking** – Track periods, predict cycle phases, and receive wellness and self-care suggestions.
- **Emotion Detection** – Uses camera-based technology to estimate emotions and provide suitable wellness suggestions.
- **Sound Therapy** – Provides frequency-based audio sessions designed for relaxation and stress relief.
- **Gesture Controls** – Allows users to interact with the application using hand gestures.
- **Stress-Relief Games** – Includes simple interactive games for relaxation and mental breaks.
- **AI Help Chatbot** – Helps users understand and navigate the different features of the platform.
- **Contact Support** – Allows users to communicate with the WellSync team.

## Technology Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **AI & Computer Vision:** TensorFlow, TensorFlow.js, OpenCV, NumPy
- **Database:** MySQL
- **Additional Tools:** HandPose, Font Awesome
